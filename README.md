# 🍽️ Food Ordering Behaviour and Consumer Trends

> A Tableau-based Data Analytics project completed as part of the SkillWallet/ SmartBridge Program.

---

## 📌 Project Overview

This project analyzes food ordering behaviour and consumer trends using Tableau. It transforms raw restaurant order data into meaningful insights through interactive visualizations, dashboards, and stories. The project helps understand customer preferences, cuisine popularity, restaurant performance, meal choices, customer ratings, repeat ordering behaviour, and city-wise ordering trends.

---

## 🎯 Project Objectives

- Analyze customer food ordering behaviour.
- Identify the most popular cuisines.
- Compare restaurant performance.
- Analyze meal type preferences.
- Study customer ratings and repeat orders.
- Identify top-performing cities by order volume.
- Develop an interactive Tableau Dashboard.
- Present business insights through a Tableau Story.

# 📖 Tableau Story

The Tableau Story presents business insights using multiple interactive visualizations to explain customer ordering behaviour, cuisine demand, restaurant performance, and ordering trends.

---

# 📈 Key Insights

- Desserts and Fast Food received the highest number of customer orders.
- Premium restaurants generated the highest average order value.
- Dinner was the most preferred meal type.
- Mumbai recorded the highest order volume among the selected cities.
- Customer ratings remained consistent across different meal types.
- Repeat customers contributed significantly to overall orders.
